不会 Git，也能把作品发到 GitHub

EasyHub 是面向新手的 GitHub 客户端。选一个文件夹，写一句“这次改了什么”，点一下就发布。问题、合并请求和新版本也都在同一个地方处理。

功能

日常要做的事，都变成了按钮

选文件夹就能发布

自动找出新增、修改和删除的文件。勾选这次要发的改动，写一句说明，点“发布源码”。没勾选的继续留在电脑上。

不会悄悄覆盖文件

发布前先看看 GitHub 上有没有新内容。同一个文件两边都改过时，会把两个版本摆出来，让你选留哪个。

发布新版本

写好版本号和介绍，附上安装包等下载文件。可以先预览，确认后再发布；没写完的下次接着写。

问题和合并请求

首页“等你处理”列出待回复的问题和待审查的合并请求。看完改了什么，再决定合入还是关闭。

AI 帮你看改动可选

填上自己的 API Key，AI 会总结改了什么、指出可能的问题。发送前先告诉你要发什么，合不合入还是你说了算。

发现好项目

搜索公开项目和用户，看看今天、本周的 EasyHub 热门。英文介绍和问题可以一键翻译成中文。

怎么用

三步发布第一个作品

用 GitHub 登录

在浏览器里完成授权就行，不用另外注册 EasyHub 账号。

选择项目

添加电脑上已有的文件夹，下载自己在 GitHub 上的项目，或者新建一个。

写一句说明，发布

看看改了哪些文件，写下这次改了什么，点“发布源码”。

还没准备好登录？先打开模拟项目随便点点，不会上传到 GitHub。
