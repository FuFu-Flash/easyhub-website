1.2.0 换了新的签名，从旧版升级要先卸载

1.1.0 及更早的安装包用的是公开的调试签名，别人也能做出同签名的假安装包。从 1.2.0 起改用 EasyHub 自己的签名。卸载旧版后需要重新登录 GitHub，你在 GitHub 上的项目不受影响。

功能

出门在外，也能跟上项目

手机直接读取 GitHub 上的内容。电脑上发布了更新，手机打开项目就能看到。

首页就是待办

“等你处理”把同一个项目的问题和待审查的合并请求合成一行，其余的折叠起来，打开就知道先做什么。

看到问题，直接回复

提出、回复、关闭或重新打开问题，在手机上也能和使用你项目的人继续交流。

合并请求，先看清楚

查看改了哪些文件。批准合并前会显示改动文件数和检查结果，检查没通过会提醒你。

项目和版本都在手里

阅读项目介绍、修改记录和发行说明，选好文件直接下载到手机，能看到进度，也能取消。

发现好项目

搜索公开项目和用户，看看 EasyHub 热门。外文介绍和问题可以一键翻译。

深色模式

在设置的“外观”里选跟随系统、浅色或深色，配色和桌面版一致，晚上看也不刺眼。

和桌面版的分工

手机随身看，电脑来发布

两边登录同一个 GitHub 账号，项目、问题和版本通过 GitHub 保持一致。

手机上可以

  • 查看自己的项目和公开项目
  • 提出和回复问题
  • 审查、合并或关闭合并请求
  • 新建项目、下载发行版

需要用桌面版

  • 管理电脑上的项目文件夹
  • 发布源码
  • 发布或编辑新版本
